# Official Pololu reference archive / 官方资料库

完整原文手册见 manual.html / manual.pdf，覆盖组装、控制板、显示器、指示灯、供电、电机版本、编码器、反射探头、IMU、接口、引脚、编程和故障恢复。另保存 LCD/OLED 控制板、整车及底盘尺寸图。sources.json 逐项列出来源和 SHA-256；linked-resources.json 提供手册内进一步技术资源链接。此处是官方原文快照，不是对整个 Pololu 网站所有内容的抓取，也没有下载全部 CAD/STEP 模型。

CHA03A 是底盘编号，不区分 LCD/OLED 控制板，更不区分电机版本。3pi03a 与 3pi03b 图纸第 5 页五探头相对布局一致：横向中心坐标 +30,+10,0,-10,-30 mm；相对 DN3 前后偏置 -13.5,-1.5,0,-1.5,-13.5 mm。坐标采用前方为正、左侧为正。

轮子官方名义直径 32 mm，名义半径 16 mm。有效滚动半径需实测。Standard/Turtle/Hyper 分别使用不同电机，不能仅凭底盘编号指定编码器每轮转计数。现有轮距 83.6 mm、358.3 counts/revolution 暂为历史程序值，不能宣称均为官网确认。轴中点至 DN3 的 30 mm 仍是用户近似测量；图纸中的 30.7 mm 相对于图示基准，不能自动解释为轴到探头距离。

已修正 sensor_map/geometry.example.json 中探头相对布局和名义轮半径，confirmed 保持 false；不改写历史实验数据，不重新烧录运动控制固件。运行中的旧窗口需要重开才能加载新文件。

A3 地图保持适用：图案 400×280 mm、单格10 mm，不依赖探头等间距。定位器支持每个探头独立二维坐标。图纸尺寸兼容不等于定位精度验证；起点、左右通道对应、当前高度及同纸黑白校准仍需核对，转弯外探头可能暂时越出图案。地图不能保证走正方形。
